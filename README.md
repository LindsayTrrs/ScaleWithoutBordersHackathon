# Jobagotchi
This is Jobagotchi! A **chrome extension** to assist finding legitimate, high-quality remote jobs. A project created by Yusriyah Rahman, Grishma Bakhedi, Tahrima Sultana, and Lindsay Torres for Scale Without Borders 2026. Motivation is a troubling aspect when it comes to applying to jobs, so why not have a cute, friendly friend help you to stay motivated and make sure you're applying to credited companies? Below is a step-by-step process in how to download and utilize Jobagotchi. 

## Step 1
<img width="1371" height="715" alt="Screen Shot 2026-05-24 at 11 48 46 PM" src="https://github.com/user-attachments/assets/c7160bfd-598e-46dd-af5d-fd5292298a5a" />

Clicking **<Code>** in the top right of this repository will allow you to download Jobagotchi as a ZIP file, shown at the bottom of the panel that pops up. By clicking **"Download ZIP"**, it will download all the necessary files to run our extension. Make sure to un-zip the file.

## Step 2 
Go to chrome://extensions, and it should open up a new tab of all of your existing extensions. To add a new extension, click **'Load unpacked'** and find your un-zipped file of your Jobagotchi folder. 
<img width="398" height="50" alt="Screen Shot 2026-05-24 at 11 54 50 PM" src="https://github.com/user-attachments/assets/cfccc2d0-e131-46f9-a95d-1a3657e4490a" />
From there, you should see it with the rest of your extension, and make sure that it's turned on. You might need to turn on Developer Mode to ensure it runs. 
<img width="398" height="50" alt="Screen Shot 2026-05-24 at 11 54 50 PM" src="https://github.com/user-attachments/assets/2321900b-f1b0-4910-a92a-d354a6ec80ca" />

## Step 3 
Then you can browse LinkedIn! Whenever you're on /jobs/collections, /jobs/view or /jobs/search-results.
